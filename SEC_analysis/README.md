# SEC Plotting Tool

Pipeline and GUI for SEC (size-exclusion chromatography) curves: **raw instrument CSVs → normalized Excel → Arcadia-styled SVG figures**.

## Supported proteins

| Raw data folder | Normalized Excel |
|-----------------|------------------|
| `SEC data/BSA_raw_data/` | `bsa_curves_normalized.xlsx` |
| `SEC data/DNAse_raw_data/` | `DNAse_curves_normalized.xlsx` |
| `SEC data/CytC_raw_data/` | `Cyt_C_curves_normalized.xlsx` |
| `SEC data/Hemoglobin_raw_data/` | `Hemo_curves_normalized (2).xlsx` |

All four use the same Python pipeline and the same batch SVG script and web GUI.

## Folder layout

- **`SEC data/<protein>_raw_data/`** — Raw instrument CSV exports (one CSV per condition: standards, TCEP, EDTA, TCEP+EDTA). Required for the raw→normalized step.
- **`data/`** — Normalized `.xlsx` files (Data sheet only). Filled by running Section 0 of the notebook or `python sec_raw_to_normalized.py`. The batch SVG step reads from here.
- **`output/`** — SVGs written by the batch step or the notebook.

## Pipeline

1. **Raw → normalized Excel**  
   Run Section 0 of `sec-plot-workflow.ipynb`, or from the repo root:
   ```bash
   python sec_raw_to_normalized.py
   ```
   Reads CSVs from `SEC data/<protein>_raw_data/`, writes normalized Excel into `data/` by default so the batch SVG step can read from there.

2. **Normalized Excel → SVG**  
   Run Section 1 of the notebook, or `python plot_sec_to_svg.py` (after pointing it at `data/` and an output folder). Produces one SVG per Excel file.

3. **Web GUI**  
   For ad‑hoc plots from CSV (same layout as the Data sheet): `python app.py`, then open http://127.0.0.1:5000. See `RUN_GUI.md`.

## Dependencies

```bash
pip install -r requirements.txt
```

**Local:** `python app.py` then open http://127.0.0.1:5000. **Deploy** (e.g. Render): same install, start command `gunicorn app:app`.

Requires: pandas, openpyxl, matplotlib, arcadia-pycolor, flask, gunicorn. Python 3.8+.

## Repo contents (for GitHub)

- **Notebook:** `sec-plot-workflow.ipynb` — Section 0: raw→normalized for all four proteins; Section 1: batch SVG; Section 2: GUI overview.
- **Scripts:** `sec_raw_to_normalized.py`, `plot_sec_to_svg.py`, `app.py`, `sec_plot_gui.html`.
- **Config:** `sec_raw_to_normalized.SEC_PROTEIN_CONFIG` — CSV filename substring → condition name for each protein. Adjust if your filenames differ.
- **Data:** Put raw CSVs in `SEC data/<protein>_raw_data/` (or set `sec_data_dir` in the notebook). Normalized files can be generated by the pipeline or committed if under size limits.
- **Fonts (optional):** `Atkinson_Hyperlegible/` for Arcadia-style text; plots still work without it.

The HTML GUI works with any CSV that has the same structure as the Data sheet (pairs of Volume, signal columns). Export the Data sheet to CSV and upload, or use the batch-generated files.
